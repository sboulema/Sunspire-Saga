Sprite pack guide

What a pack is

One image file per thing you want to reskin, named exactly after its slot (wolf.png replaces the Fang Wolf, and so on). Load files directly, or zip any number of them — folder names inside a zip are ignored, so a zipped folder from your file manager works as-is. Accepted formats: .png, .gif (animated GIFs play their frames), .webp, and .zip containing those. Anything you load is kept in this browser's own database (IndexedDB, with room for large packs); nothing is uploaded. Only load art you made or have the rights to use.

Characters

Six frames per character, drawn at native pixel size with the feet on the tile (built-ins are 16×22). 2 is the walking frame; left-facing is mirrored from right automatically. In battle the four adepts are drawn at native size (1×) from seven more frames named like the walk frames: the idle back stance back, the two-frame attack attack/attack2 and cast cast/cast2, the single recoil frame hit when taking damage, and downed while knocked out (lying on the ground, bottom-anchored like the rest) — hero_back, ari_cast2, lyn_hit... Townsfolk never fight, so they take only the six walk frames.

Font

The game font can be replaced one character at a time with small images, the way a bitmap font sheet is cut up. Load them like any other sprite (or in the zip); every character you leave out keeps the built-in 5×5 letter, so a partial set works. File names are case-sensitive here.
A ... Zuppercase letters, 6×8
lowercase-a ... lowercase-zlowercase letters, usually 6×6 (ascenders such as l and h may use an 8-row cell)
0 ... 9digits
period comma colin semicolin questionmark exclaimationpoint apostrophe quote dash underline plus equals slash percent dollar number and at tilde line bracket-left bracket-right parentheses1 parentheses2 arrow arrow-left arrow-right spacepunctuation (colon, semicolon and exclamationpoint are accepted spellings too); space is optional and only sets the width of a space
All cells are bottom-aligned on one line: give every image the same bottom edge (the baseline plus a shadow row, if your letters have one) and draw descenders inside the cell. Glyphs are drawn at their own pixel size with one pixel of air after each (none if the image already ends in an empty column), so sets may be proportional; text wrapping follows the real widths and capitals are 8 px tall, so menus and the battle strip grow to fit. Plain dialogue text shows the glyphs in their own colours (a white glyph with a dark shadow stays that way); coloured labels such as gold headings or red HP tint the glyph in that colour.

Complete slot list

Every file name the loader accepts, generated from the game's own data so it is always current. With a pack loaded, covered slots are marked green with a tick, loaded variants are listed after their slot, and files that match no slot are called out above the list. Slots marked variants also take any suffix (name_2, name_anything...) for extra random variants. Add .png, .gif or .webp to each name.

Making a pack

  1. Draw sprites in any pixel editor (Aseprite, Piskel, GIMP...). Use a transparent background and sizes near the built-ins for the cleanest fit.
  2. Export one file per slot with the exact slot name, e.g. wolf.png. For animation, export an animated .gif instead.
  3. Load the files here — or zip the folder and load the zip. Partial packs are fine; unlisted slots keep the built-in art.
  4. Swap art any time by loading a file with the same name again, or press Reset to built-in art to remove everything.
Packs live in this browser only — on another device or after clearing site data, load the zip again.
