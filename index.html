Sunspire Saga - engine build
MIT License. Open source project. Work in progress: one town, one battle.

Tested in Chromium browsers; Firefox and Safari are untested so far, so please report what breaks.
The game needs WebGL and, for now, a keyboard.

• Controls: arrows to move, Z = A, X = B, A / S = L / R, Backspace = Select, Enter = Start.
• Press 1, 2, 3 or 4 for zoom. Double click on the screen for full screen.
• Press M to unmute. Press SHIFT + PGUP/PGDN to control the volume.
• Debug: D collision, F fps, G grid, K keys, T battle stats, L sliders, Y battle animation tester.

Check the source code on GitHub.
The engine is a fork of goldensun_html5 (MIT).
