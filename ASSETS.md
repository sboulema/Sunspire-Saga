# Assets

Origin and licence of everything under `assets/` and `static/`. Nothing here comes from Nintendo,
Camelot or any other commercial game; if you add an asset, add a line.

| Path | What | Origin | Licence |
|---|---|---|---|
| `assets/sunspire/sprites/*.png` | 255 sprites: the four adepts and their battle poses, villagers, spirits, enemies, summons, effects, map objects, battle backgrounds, icons, title | Sunspire Saga's own pixel art, exported from the legacy `game.js` with `tools/export-pack.js` | MIT (this repo) |
| `assets/sunspire/brindle_tiles.png`, `brindle_grid.json` | the Brindle town tileset and tile grid, rendered from the legacy map builder | Sunspire Saga | MIT |
| `assets/sunspire/glyphs.json` | the 5x5 bitmap font as bit strings | Sunspire Saga | MIT |
| `assets/images/**`, `assets/maps/**`, `assets/font/**` | atlases, tileset, Tiled map and BMFont generated from the three sources above by `scripts/build_sunspire_assets.js`; menu widgets, status icons, cursors and other art Sunspire never had are labelled placeholder boxes drawn by the script | generated | MIT |
| `assets/sounds/**` | placeholder chiptune WAVs (seeded tone loops and blips) generated by the same script; Sunspire's real sound is synthesised at run time in the legacy game and is still to be ported | generated | MIT |
| `assets/dbs/*.json` | the game data (characters, abilities, items, enemies, spirits, summons, shops, dialog), hand-written for Sunspire Saga | Sunspire Saga | MIT |
| `assets/dbs/abilities_animations/{attack,attack_jumping,cure}_db.json`, `assets/dbs/common_abilities_animations/*` | image-free battle animation recipes (tweens and geometry only) | goldensun_html5 engine | MIT |
| `assets/filters/*.js` | WebGL filters | goldensun_html5 engine | MIT |
| `assets/plugins/particle-storm.js` | Phaser Particle Storm plugin, bundled by the engine | Photon Storm, as shipped with goldensun_html5 | see the file header |
| `static/phaser.js` | Phaser CE 2.19.0 with the engine's patches | Photon Storm / Phaser CE | MIT |
| `static/codemirror*.js`, `mode-javascript.js` | CodeMirror for the debug editor | CodeMirror | MIT |
| `static/styles.css`, `home.js`, `favicon.ico`, `manifest.webmanifest`, `humans.txt`, `robots.txt` | site shell | goldensun_html5 engine, edited for Sunspire; the favicon still needs replacing with Sunspire's | MIT |

Removed from the upstream engine in the Sunspire fork: every Golden Sun sprite, tileset, map,
font, sound, database entry and battle animation, the GS battle-mechanics FAQ under `help/docs`,
the GS logo and the upstream site's analytics script.
