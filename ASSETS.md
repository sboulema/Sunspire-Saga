# Assets

Origin and licence of everything under `assets/` and `static/`. Nothing here comes from Nintendo,
Camelot or any other commercial game; if you add an asset, add a line.

| Path | What | Origin | Licence |
|---|---|---|---|
| `assets/sunspire/sprites/*.png` | 255 sprites: the four adepts and their battle poses, villagers, spirits, enemies, summons, effects, map objects, battle backgrounds, icons, title | Sunspire Saga's own pixel art, exported from the legacy `game.js` with `tools/export-pack.js` | MIT (this repo) |
| `assets/sunspire/sprites/fence_h.png`, `fence_post.png`, `fence_v.png`, `fence_v2.png` | the fence run tile and three posts | drawn by the project's author for the engine build (2026-10-28), converted from GIF with `tools/gif2png.js` | MIT (this repo) |
| `assets/sunspire/recipes/quake_db.json` | the Quake battle animation recipe (data: sprite positions, tweens, shake) | goldensun_html5's `assets/dbs/abilities_animations/quake_db.json`, unchanged | MIT (upstream engine) |
| `assets/images/abilities_animations/quake.png` | the column of earth the Quake recipe animates | **placeholder** drawn by `scripts/build_sunspire_assets.js` with the geometry the recipe expects; the upstream engine's own sheet is the original game's art and stays out of this repository (load it as the `quake` pack slot) | MIT (this repo) |
| `assets/sunspire/maps/<id>_tiles.png`, `<id>_grid.json` | the five maps' tilesets and tile grids (Thera Fields, Brindle, Brindle Mine, Sunspire Trail, the Sunspire), rendered from the legacy map builders | Sunspire Saga | MIT |
| `assets/sunspire/glyphs.json` | the 5x5 bitmap font as bit strings | Sunspire Saga | MIT |
| `assets/sunspire/content.json` | the game's data and story, ported from the legacy `game.js` | Sunspire Saga | MIT |
| `assets/images/**`, `assets/font/**` | atlases and BMFont generated from the sources above by `scripts/build_sunspire_assets.js`; menu widgets, status icons, cursors and other art Sunspire never had are labelled placeholder boxes drawn by the script | generated | MIT |
| `assets/maps/**`, `assets/dbs/*.json` (most), `walkthrough.html` | Tiled maps, databases and the walkthrough generated from `content.json` by `scripts/build_sunspire_content.js` and `scripts/build_walkthrough.js` | generated | MIT |
| `assets/sounds/**` | placeholder chiptune WAVs (seeded tone loops and blips) generated by the same script; Sunspire's real sound is synthesised at run time in the legacy game and is still to be ported | generated | MIT |
| `assets/dbs/misc_animations_db.json`, `interactable_objects_db.json`, `assets/init.json` | hand-written engine configuration for Sunspire Saga | Sunspire Saga | MIT |
| `assets/dbs/abilities_animations/{attack,attack_jumping,cure}_db.json`, `assets/dbs/common_abilities_animations/*` | image-free battle animation recipes (tweens and geometry only) | goldensun_html5 engine | MIT |
| `assets/filters/*.js` | WebGL filters | goldensun_html5 engine | MIT |
| `assets/plugins/particle-storm.js` | Phaser Particle Storm plugin, bundled by the engine | Photon Storm, as shipped with goldensun_html5 | see the file header |
| `static/phaser.js` | Phaser CE 2.19.0 with the engine's patches | Photon Storm / Phaser CE | MIT |
| `static/codemirror*.js`, `mode-javascript.js` | CodeMirror for the debug editor | CodeMirror | MIT |
| `static/favicon.ico`, `static/icons/*.png` | Sunspire's favicon, app icons and logo, from the legacy site's `tools/logo-gen.html` | Sunspire Saga | MIT |
| `static/styles.css`, `home.js`, `site.css`, `site.js`, `manifest.webmanifest`, `humans.txt`, `robots.txt` | site shell | goldensun_html5 engine and the legacy Sunspire site, edited | MIT |

Removed from the upstream engine in the Sunspire fork: every Golden Sun sprite, tileset, map,
font, sound, database entry and battle animation, the GS battle-mechanics FAQ under `help/docs`,
the GS logo and the upstream site's analytics script.
